# MCTier v3.4.0 更新日志

以下根据 v3.3.0 标签至当前源码的实际差异整理；无特别说明的聊天室功能同时覆盖桌面端与安卓端、大厅与私聊。

- 修复随机大厅密码生成后被误判为长度不合法的问题，区分手动密码、加密凭据与界面占位值，保持原有密码长度及强度校验。
- 完善最近大厅、收藏大厅、自动大厅、分享邀请和二维码中的加密密码处理；自动填入仍隐藏明文，分享内容使用加密邀请凭据。
- 表情库升级为动态 GIF 表情，内置资源按需下载至本地缓存，完整缓存可直接复用，无需每次联网下载。
- 内置表情支持下载进度、10 路并发、部分缓存恢复与失败自动退避重试，单个表情下载失败不会阻断整批资源。
- 新增“最近”“自定义”表情分类，支持批量导入 GIF、PNG、JPEG 等图片，将自己或他人发送的图片加入表情库并快捷发送。
- 支持新增、重命名、删除自定义分类，以及删除非内置表情、在分类之间移动表情；消息菜单统一使用“添加到表情库”。
- 桌面表情选择器改为紧凑的底部面板，分类栏支持普通鼠标滚轮横向滚动；面板展开时消息区同步调整大小，点击输入框或文件按钮自动收起。
- 修复动态表情发送后显示为“[表情]”、部分消息弹幕显示附件 JSON，以及图片/GIF 展示尺寸不协调的问题。
- 新增聊天记录模糊搜索，支持展示多个匹配结果并定位原消息；桌面 Ctrl+F 打开应用内聊天搜索，避免弹出浏览器原生查找框。
- 完善聊天文件消息与按类型预览，图片直接显示，视频显示缩略帧与播放入口，音频显示名称、播放控制和进度；发送文件入口同时支持图片，移除重复的图片按钮。
- 图片、GIF、图片文件及他人的自定义头像复用全屏图片查看器，支持放大查看；修复预览弹层偏移、居中及遮挡问题。
- 提供 PDF、文本、Word 内容、Excel 工作表及 PPTX 幻灯片画面预览；过滤空白工作表，PPTX 不再仅显示提取文本。
- 新增 ZIP、7z、RAR、TAR 及常见压缩 TAR 文件的目录树预览，可查看内部文件和文件夹层级。
- 文件消息支持右键下载，预览界面提供显式下载入口；图片悬停下载按钮、文件操作反馈与失败提示更清晰。
- 新增长按输入框录制语音消息和上划取消，修复安卓长按时误弹键盘、原生文本菜单干扰、松手未发送及录音期间按钮位移等问题。
- 录制聊天室语音消息时暂停向大厅实时语音链路发送麦克风内容，录制结束后按用户原有麦克风状态恢复，避免录音内容同时广播给全大厅。
- 双端使用定制语音消息气泡，支持拖动进度播放；气泡宽度随时长变化，10 秒达到最大宽度，同时保留播放按钮和时长的必要空间。
- 新增离线语音转文字，识别结果直接显示在对应语音消息下方；内置 sherpa-onnx 与 Zipformer-CTC 中文 INT8 模型，压缩模型和词表合计约 19.80 MB，首次使用本地解压，无需运行时下载或上传录音。
- 增强实时语音健康检测与自动恢复，修复协商冲突、旧连接回调、提前到达的 ICE 候选、音轨绑定和播放恢复等问题，降低单向无声及通话中断的发生概率。
- 桌面端增加对已安装 NVIDIA Broadcast / RTX Voice 麦克风的检测与使用选项，支持全局设置和大厅内覆盖。
- 修复聊天室监听中断后未完整恢复的问题，增加连接保活检测、断流重连和有限历史消息补偿，改善跨端单向收不到消息的情况，并避免旧大厅消息混入和重复提醒。
- 私聊玩家列表新增置顶、标记未读和免打扰，桌面支持右键、安卓支持长按；设置按受保护的稳定身份保存，对方离开重进或改名后仍可恢复。
- 完善私聊免打扰与未读统计的配合：免打扰仍可接收和查看消息，但不触发对应的声音、弹幕与全局未读提醒；查看会话时清除手动未读标记。
- 玩家列表、大厅和私聊中的其他玩家自定义头像支持点击全屏查看，首字符头像保持无操作，自己的头像保留原有编辑行为。
- 消息弹幕按文本、图片、表情、视频、语音、音频和其他文件分别展示；支持图片预览、视频缩略图及可读的附件信息，失败时不再退回协议 JSON。
- 调整昵称、头像与气泡间距，修复文件和语音气泡遮挡头像、对齐不一致等问题；图片气泡使用无三角样式，文本、语音和文件保持一致的消息布局。
- 修复右键菜单偏离点击位置，按实际菜单尺寸与屏幕边界定位；完善添加表情、分类管理、下载等操作的成功/失败提示及提示层级。
- 完善双端聊天室、表情栏、录音提示、搜索、消息气泡及文件预览控件的明暗主题适配；修复亮色模式下按钮文字、悬停和图标配色异常，发送按钮可用时保持绿底白图标。
- 拆分桌面 Tauri 命令与信令信任边界模块，修复窗口 Hook 调用顺序，更新存在安全问题的前端依赖，并增强远程控制会话授权及特权资源路径检查。
- 配套信令服务器完成连接处理、共享状态、安全策略和配置模块重构，修复密码失败记录容量限制误伤无关用户的问题。
- 改进 Windows 构建目录识别与产物导出校验，校验版本号及文件 SHA-256，补充双端聊天、媒体、表情、密码、语音恢复和主题相关回归测试。

## 兼容性说明

- 内置语音识别模型主要面向中文；19.80 MB 是压缩模型资源体积，不含推理引擎，也不是整个安装包或解压后的大小。
- PPTX 支持静态页面画面，不保证 PowerPoint 的全部动画和高级效果。旧版二进制 Office 格式在 Windows 上部分依赖本地 Office 转换；安卓遇到不支持的旧格式仍需先转为 DOCX、XLSX、PPTX 或 PDF，不能宣称所有 Office 格式完全等价预览。
- 音视频预览受系统解码能力影响；压缩包只预览目录和文件列表，不预览包内文件内容。
- 私聊偏好保存在当前设备，依赖对方新版客户端的稳定身份，不会自动同步到自己的其他设备。
- 自动恢复与自动重试不能保证绕过所有网络、防火墙、下载源或硬件问题；本版本仍需更多真实跨网络、长时间通话及安卓设备验证。
