# 表情面板、消息弹幕与语音压缩

Windows 和 Android 在消息区域按下鼠标或触摸屏幕时收起表情面板。使用事件观察，不消费事件，消息原有的滚动、长按和预览入口仍可用。

两端弹幕不再显示额外操作按钮。直接点击文本复制正文，点击语音播放已收到的录音，点击图片保存原图，点击文件、音频附件、视频附件、文档或压缩包下载原文件。缩略图只是展示，不能代替下载原件。未知纯文本回退到复制，带有效附件元数据的消息始终下载。每条弹幕防止重复点击触发多次下载，成功/失败均有反馈。

Windows 悬停暂停方便点击，也支持 Enter/空格触发。Android 每条弹幕使用独立的、尺寸随内容变化的悬浮窗口；按下暂停，松手完成点击后立即操作并恢复移动。点击窗口外、鼠标移开或触摸暂停满 8 秒后也会恢复。空白区域不设置可触摸的整屏窗口，弹幕窗口不获取键盘焦点。同时最多保留 24 条。两端一次仅播放一条弹幕语音，关闭弹幕时释放播放器。Windows 下载保存在下载目录的 MCTier 子目录，Android 使用现有相册/下载保存路径。

语音压缩只适用于新录制的聊天语音，不修改实时语音通话、收到的语音或作为文件上传的音乐：

| 平台 | 首选编码 | 回退 |
| --- | --- | --- |
| Windows | 单声道 Opus，目标 16 kbps，WebM/Ogg | 浏览器仅支持 MP4 时使用目标 24 kbps |
| Android 10+ | 单声道 Opus，目标 16 kbps，Ogg | AAC-LC 单声道 16 kHz、24 kbps，MP4 |
| Android 8–9 | AAC 单声道 16 kHz、24 kbps，MP4 | 设备录音失败时提示重试 |

两端均在录音期间直接编码。Android 使用 MediaRecorder，松手只需结束容器和读取小文件，不再等待整段 PCM 二次编码；最多录制 60 秒，临时文件在成功、取消或异常时清理。旧 WAV 调用仍有兼容编码路径。发送和本地播放使用同一份压缩字节及正确 MIME。接收协议支持 WebM、Ogg、MP4 和 WAV，无需改变协议版本。

新图片和语音先显示本地“发送中”消息，再更新为实际发送结果；失败保留明确的失败状态。Android 文件选择也先显示准备附件消息。显示本地消息不代表网络已经送达，实际接收速度仍取决于文件大小与网络。

按目标码率估算，一分钟 Opus 约 120 KB、AAC 约 180 KB，另加封装开销；原 Android WAV 约 1.92 MB。实际大小受设备编码器、内容和可变码率影响，不能保证每条语音固定大小。压缩为有损，人声清楚优先，不作音乐保真承诺。

验证覆盖弹幕各类型点击分流、防重复触发、原件下载元数据、语音数据校验、播放/停止/错误回收、录音码率与取消时序以及两端编译。当前无 Android 真机，系统悬浮窗触摸、设备 MediaRecorder 编码输出和跨端听感尚需真机验证。
