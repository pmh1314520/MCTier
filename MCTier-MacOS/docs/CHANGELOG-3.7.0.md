# MCTier 3.7.0 更新日志

相较于 3.6.0 发布提交 `adaaa70`，包含其后的 Android 蓝牙修复及本次发布改动。

- 修复 Android 加入大厅后强制切换音频路由、导致蓝牙耳机声音转为手机外放的问题；大厅语音使用媒体音频输出，保留系统蓝牙 A2DP 路由。
- 移除 Android 语音期间周期性重设音频路由的守护循环，改为状态变化时调整并延迟校正一次，针对蓝牙声音反复播放数秒后中断的问题进行修复。
- 调整 Android 麦克风管理：开麦优先使用手机内置麦克风，避免切换到蓝牙 SCO 通话链路；静音及录音占用期间同步控制底层麦克风，离开大厅时恢复普通音频模式。
- 修复 Android 消息弹幕出现时顶部悬浮区域可能拦截其他应用点击、长按和拖拽的问题；弹幕窗口始终不接收触摸，并取消悬浮弹幕的点击暂停、复制和下载操作，相关操作可在聊天室中完成。
- 适配 Android 12 及以上的悬浮窗触摸安全限制，按系统允许的遮挡透明度限制弹幕窗口；无弹幕时窗口完全透明，关闭时取消动画并重置轨道状态。
- 修正桌面大厅及双端游戏 HUD、连接诊断中的状态提示：探测失败显示为“不可达”，避免把聊天端口探测失败误称为成员“离线”；补充说明此状态不等于离开大厅，也不能单独判断语音连接状态。
- 扩充 Android“无法联机？”帮助，补齐桌面端已有的四种 Minecraft 正版／离线模式组合说明、mcwifipnp 模组说明，以及房主虚拟 IP 和局域网端口的查找与使用提示。
- 更新中文 README 的粗体赞助者名单及按时间排列的赞助记录，包含 wdz、Forever；英文 README 继续不包含赞助者名单，双文档版本徽章同步到 3.7.0。
- 修复 Windows 构建时 Sherpa 语音识别依赖下载不稳定的问题：新增代理识别、断点续传、最多八次重试、文件大小与官方 SHA-256 校验，以及校验成功后的本地缓存复用。
- 补充 Windows Sherpa 构建说明和下载失败、续传、损坏文件处理的回归测试，并完善未完成下载及依赖缓存的 Git 排除规则。
- 统一桌面应用、Android、包锁文件及第三方声明中的版本信息为 3.7.0；本次 Android 发布版本为 3.7.0-android，versionCode 为 89。

验证：Windows Release EXE、NSIS 安装包及 Android APK 已构建成功；下载恢复与产物导出回归测试通过。蓝牙持续播放和游戏长按／拖拽仍需在受影响手机上复测。

说明：英文 README 及双向语言跳转、纯内置表情包、自定义虚拟 IP、NVIDIA 设置调整均已存在于 3.6.0，不作为本版本新增功能。外层一键脚本 `update_version.ps1` 已接入 Sherpa 准备步骤，但位于本次桌面应用源码仓库范围之外。
