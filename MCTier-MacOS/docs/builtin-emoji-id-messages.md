# 内置表情 ID 消息

Windows 与 Android 的内置 GIF 共用 `shared/builtin-emoji/builtin-v3.pack.gz`。启动时在后台检查并解压到各端应用缓存，聊天界面和表情面板复用同一次准备过程；完整缓存存在时无需再次解压。

资源包现有 566 个表情，已移除重复的 `1f60d`，保留 `1f970`。两端启动时清理旧缓存中的重复条目；历史消息中的 `mctier:emoji:v3:builtin-1f60d` 会解析为 `builtin-1f970`，不再提供重复的发送入口。

选择内置表情后，使用现有加密文本消息发送 `mctier:emoji:v3:builtin-<资源 ID>`，不携带 GIF、Base64 或附件。群聊、私聊、消息去重及撤回继续使用现有通道。自定义表情保持图片传输。

接收端仅对完整匹配协议的文本进行解析，只能从本地解压索引寻找资源，不允许远端指定路径或 URL。聊天消息呈现 GIF 气泡，可放大查看；搜索、引用和弹幕使用表情摘要或本地图片。解压尚未结束时显示准备状态，失败可重试；未知 ID 显示更新应用提示。

两端需要升级到支持此协议的版本；旧版本会把 ID 显示为普通文本。资源包更新时若改变 ID 对应内容，应同时升级协议中的资源包版本，避免同一 ID 在不同客户端显示不同图片。

Android 分享画质入口：进入大厅 → 屏幕共享 → 共享画质。分辨率、帧率和码率需在开始分享前选择；正在共享时先停止再调整。选项传递到 MediaProjection/WebRTC 采集和编码，并在成功启动后保存。

验证涵盖共享资源包全部 ID、非法路径/换行/版本拒绝、文本发送及私聊收件人保留、并发解压复用、摘要与撤回，以及两端分享画质参数。实际设备性能和跨设备播放仍需实机验证。
