# MCTier 3.10.0

相较于 GitHub 上的 3.9.5（`e8d792d`）：

- 双端明确区分手动创建与加入大厅：创建时遇到已占用的名称，提示更换名称；加入时先检查大厅存在，再校验密码，不再通过“加入”意外创建大厅。
- 修复桌面端尚未通过服务器校验就进入大厅页面的问题；注册和本地会话初始化成功后才显示大厅，失败时保留表单及完整错误提示。
- 修复 Android 创建或加入失败后缺少明显提示的问题，在操作按钮下方显示可换行的完整失败原因。
- 优化桌面端创建／加入错误提示，采用小图标、细边框和淡红背景的紧凑提示条，移除重复大标题，并适配亮色与暗色主题。
- 完善连接失败后的资源清理、重试及强制停止处理；连接过程中按 Esc 不再提前关闭桌面表单。
- 保留自动大厅、断线重连和大厅重载，避免已获准进入的会话在恢复连接时被误判为重复创建；虚拟 IP 冲突恢复时正确保留首次进入或重连模式。
- 双端大厅动态设置新增文件共享下载目录设置，与软件设置共用持久化配置，支持选择目录及恢复默认，无需退出大厅，后续下载使用新目录。
- Android 文件共享浏览器新增“全选／取消全选”，可批量选择当前目录中的文件，保留单独勾选、清空和下载选中功能；不递归选择子目录。
- 修复 Android 保存大厅网络配置时，旧表单数据可能覆盖刚修改的下载目录、音色和弹幕等即时设置的问题。
- 桌面端我方文字、语音和文件消息气泡统一使用 `#45bd00` 绿色，气泡尾角同步调整，覆盖亮色与暗色主题。
- 配套信令服务器新增创建／加入模式校验，在同一把大厅写锁内处理名称检查和创建，防止多个客户端同时成功创建同名大厅；旧客户端未携带新字段时保留兼容行为，最低客户端版本要求保持 3.8.0。
- 新客户端连接未升级的信令服务器时给出明确的管理员升级提示，避免静默退回混合创建／加入逻辑；使用私有信令服务器的用户需先升级服务端。
- 补充大厅准入、注册生命周期、下载目录和 Android 全选的回归测试，并完成正式 WSS 上的双端注册及旧客户端格式兼容验证。

验证范围：桌面 315 项测试、服务端 70 项测试、Android 88 项 JVM 测试及相关构建通过。MuMu 专项通过；完整桌面点击流程、VPN／游戏联机、语音媒体及远程文件实际传输未在本轮完整实测。
