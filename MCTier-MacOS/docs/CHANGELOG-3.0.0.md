# MCTier v3.0.0 发布日志

> 相较 v2.7.5 的正式版更新说明

## 发布概览

v3.0.0 是一次跨端功能和网络基础设施升级。桌面端与 Android 端统一到新的大厅、聊天、媒体共享和安全协议；官方默认信令服务器切换为：

```text
wss://mctier.pmhs.top/signaling
```

自定义信令服务器仍然受支持。已有邀请链接中携带的自定义服务器不会被覆盖。

## 新增功能

### 跨平台大厅

- Windows 与 Android 可加入同一个大厅，统一显示成员昵称、虚拟 IP、虚拟域名、麦克风状态、头像和共享资源。
- 支持无密码大厅；有密码大厅继续使用大厅名称和密码进行隔离。
- 大厅人数上限、公开大厅广场、房主转让、踢出成员、禁言和大厅动态设置均可在双端使用。
- 邀请链接和二维码支持携带 EasyTier 节点、信令服务器和大厅参数，减少跨节点加入失败。
- 新增/完善最近大厅、收藏大厅和公开大厅节点信息的恢复逻辑。
- 加入失败、服务器拒绝版本、节点不可达等情况会显示明确状态，并清理残留网络状态。

### 聊天室与私聊

- 聊天室分为“大厅”和“私聊”分页，私聊玩家列表集成在当前聊天室内。
- 点击玩家条目进入一对一会话，支持文本、图片、引用消息、撤回消息和历史排序。
- 私聊消息只发送给指定接收者；接收方只显示属于自己的私聊内容，不能通过普通大厅接口读取其他人的私聊。
- 双端分页、玩家条目和聊天室入口均显示未读数量；单数显示圆形徽标，多位数显示红色胶囊，100 条及以上显示 `99+`。
- 当前正在查看的会话收到消息会立即视为已读，不再产生该玩家的红点或重复提示音。
- 未读状态按会话和消息 ID 记录，切换玩家、离开再进入聊天室不会错误恢复已读消息。
- 快速连续发送的消息使用单调递增消息 ID 和稳定排序，降低网络乱序导致的显示顺序错误。
- 输入法组合态回车不会误发送；普通 Enter 仍可发送，Shift+Enter 保留换行。
- 消息链接、图片、@提醒、引用摘要和撤回状态均做了长度、格式和安全校验。

### 语音

- 修复 Android 加入大厅时处于静音状态，桌面端后续无法绑定正确麦克风发送轨道的问题。
- 桌面端与 Android 端统一处理 Unified Plan 音频轨道和远端回调。
- 原声模式绕过不必要的 WebAudio 处理链，减少延迟和设备兼容问题。
- 变声模式保留稳定输出轨道，切换音色无需重复建立整条连接。
- 启用浏览器/原生 WebRTC 的回声消除、自动增益和噪声抑制能力。
- 修复麦克风切换、静音、解除静音和网络重连后的发送状态同步。

### 屏幕共享

- Windows 与 Android 均支持发起和观看屏幕共享。
- Android 支持整屏采集和 Android 14+ 单个应用采集，并处理采集尺寸变化与内容可见性变化。
- 观看界面在连接开始后立即显示，提供连接中、首帧等待、失败和重试状态。
- 观看窗口关闭、按 Esc 返回、重试或重新打开时会正确释放旧视频轨道和 PeerConnection。
- 屏幕共享使用房主协调的浅层中继拓扑，减少共享者上行压力，并限制每个健康观众的下游边数。
- 修复桌面观看 Android 共享时使用远程控制 `sessionId` 鉴权，导致共享 Offer/Answer/ICE 被拒绝的问题。
- 修复中继路由与旧版直连回退互相替换连接的问题；已有新路由时不会再启动旧版直连 Offer。
- 修复旧连接的迟到 ICE、轨道回调和首帧回调污染新连接的问题。
- 增加首帧解码检查、RTP 健康监视、源帧序号、发送帧序号和带宽限制状态。
- 信令服务器完整转发共享健康字段和失败原因，不再在序列化过程中丢失。
- 修复观看 Android 共享时停留在“屏幕共享”页面或持续“等待画面”的状态管理问题。

### 远程控制

- Android 远程控制工具栏支持键盘、右键、主页、最近任务和结束控制。
- 键盘输入框删除按钮发送 Backspace；按钮使用向左箭头图标。
- 移除顶部重复的“返回/ESC”工具按钮，避免与页面返回逻辑混淆。
- 修复鼠标按钮和键盘事件发送后的状态同步、坐标换算及连接关闭清理。
- 全局快捷键支持保留系统和其他软件的监听，不再无条件吞掉 F2 等按键；用户自定义快捷键同样遵循冲突规避逻辑。

### 文件共享

- 支持双端共享文件夹、浏览目录、下载文件和密码保护共享。
- 下载路径输入框增加左右内边距，窄屏下也不会贴住容器边缘。
- 下载使用临时文件、唯一文件名和不覆盖提交，降低并发下载和部分写入导致的文件损坏风险。
- ZIP 解压增加路径规范化、目录穿越防护、大小和条目预算限制，并在失败时回滚。

### 头像与成员资料

- 桌面端和 Android 端均支持自定义头像。
- 修复 Android 自定义头像在重新进入大厅后退回昵称首字符的问题。
- 修复 Android 设置头像后桌面端不刷新对方头像的问题。
- 成员列表、聊天消息、私聊玩家列表和远程功能入口统一使用最新头像。
- 头像读取限制尺寸、格式和数据大小，拒绝不安全或过大的图片数据。

## 安全与隐私改进

- 信令服务器改为挑战签名注册，身份由注册公钥和服务器分配的会话代数绑定。
- 服务器转发前校验注册连接的 `from`、目标大厅和目标成员，拒绝伪造身份、跨大厅转发和旧连接事件。
- 大厅聊天使用逐成员签名和会话令牌；聊天和文件授权在会话同步失败时默认拒绝。
- 私聊在发送端、接收端、桌面 Tauri 命令、Android P2P 层和服务端均做接收者校验。
- 文件下载、文件浏览、共享密码、临时文件和 ZIP 解压均增加边界检查与路径防护。
- SDP、ICE、玩家 ID、昵称、密码、路由版本、消息长度和健康计数器均有格式和大小限制。
- 屏幕共享密码不能以空字符串绕过；中继观众不能使用旧版直连路径绕过房主路由分配。
- WebSocket 有消息大小、帧大小、消息频率、出站预算、连接数和发送超时限制。
- Android 组件默认不导出，网络安全配置关闭无范围明文流量；深链路由会清除 URI 中的敏感参数。
- 特权命令、文件系统访问、外部链接、进程启动和网络目标使用白名单及参数校验。
- 信令服务器以非 root 用户运行，用户投稿节点会限制目标地址，拒绝回环、私网、元数据和不可达地址。

## 网络与重连

- 桌面端、Android 端和共享服务统一使用 ICE host 候选、国内 STUN 兜底、持续候选收集、MAXBUNDLE 和 RTCP mux。
- WebSocket 断线时区分传输断开、注册失败、版本拒绝和大厅成员变化，避免重复连接抖动。
- 同一玩家重新连接后，旧连接的延迟关闭不会删除新会话。
- 屏幕共享路由带版本号，旧路由的 Offer、Answer、ICE、健康和失败消息不会覆盖新路由。
- 语音、聊天、远控、文件共享和屏幕共享分别清理自己的连接和缓存，避免跨功能状态污染。

## 界面与可用性

- 桌面端与 Android 端聊天室分页、私聊列表、红点、引用、撤回和返回路径统一。
- Android 私聊会话标题提供返回玩家列表的箭头，当前玩家名右对齐显示。
- 私聊玩家列表采用紧凑布局，减少无意义留白，长昵称支持省略显示。
- 屏幕共享失败界面提供重试入口；观看者关闭后不会被迟到的异步结果重新打开。
- 设置、大厅、文件共享、远程控制和聊天室的错误提示补充中英文文案。
- 主题、深色模式、窄屏布局、输入框边距、徽标文字垂直居中和触控区域均做了适配。

## 构建与发布

- 版本统一为桌面端 `3.0.0`，Android `3.0.0-android`。
- `一键更新MCTier版本.bat` / `update_version.ps1` 继续作为完整打包入口，生成 Windows EXE、NSIS 安装包和 Android APK。
- Android 构建增加许可证与第三方声明资产同步，确保离线安装包包含所需文本。
- Android JVM 测试任务修复 Kotlin 编译输出发现问题，安全和聊天排序测试实际执行。
- 新增桌面媒体、聊天未读、信令鉴权、服务端转发和安全边界测试。
- 发布前应同时更新两个客户端和云端信令服务器；客户端打包脚本不会自动更新云端 Docker 服务。

## 升级注意事项

1. 从 v2.7.5 升级后，建议桌面端和 Android 端都更新到 v3.0.0，避免旧客户端缺少挑战注册、聊天鉴权和共享路由字段。
2. 正式客户端默认连接 `wss://mctier.pmhs.top/signaling`。自建服务器用户继续在设置或邀请链接中填写自己的 WSS 地址。
3. 云端信令服务器需要使用 v3.0.0 对应源码重新构建 Docker 镜像；仅重启旧容器不会加载新的共享转发字段和安全校验。
4. WebRTC 仍受本地网络、NAT、防火墙、系统权限、Android MediaProjection 和运营商网络影响；STUN 是连通性兜底，不等同于 TURN 中继。
